## 怎么读

**手机 / 网页**：直接点上面的表格进入模块导航，再点小节标题。所有链接都是标准 Markdown 链接，跳转正常。

**本地（推荐，功能最全）**：

```bash
git clone https://github.com/unluckyhope/bigdata-warehouse-notes.git
```

用 Obsidian「打开本地仓库」选中该目录即可。Obsidian 里能用到双链跳转、关系图谱、反向链接。

## 笔记约定

- 目录：`序号 模块N 主题`，两位序号保证排序稳定
- 小节文件：`模块号-小节号 标题.md`，例 `03-04 数据倾斜的 6 种打法.md`
- 每篇结构：一句话结论 → 心智模型 → 核心知识点 → 动手实验 → 生产坑点清单 → 面试追问 → 自测题 → 关联小节
- 模块导航：`00_模块N导航.md`，含小节清单表、核心问题、与其他模块的关系、复盘区
